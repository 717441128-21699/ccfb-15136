# 孵化场照蛋分析系统

整盘照蛋图 → 自动分蛋 → 四类判别（受精/无精/早死胚/晚死胚）+ 发丝裂纹检测 → 盘统计 → 种鸡舍追溯。

## 运行

```bash
npm install
npm run dev        # 开发（默认 http://localhost:5173）
npm run build      # 类型检查 + 产物构建（dist/）
npm run validate   # 指标自检：合成 16 盘带真值照蛋图，输出一致率/裂纹检出率/耗时
```

页面内「照蛋结果 → 系统自检」可在浏览器里走真实 WebGL2 管线复测同一组指标。

## 验收指标（合成真值实测）

| 指标 | 目标 | CPU 管线 | WebGL2 管线（无头 Chrome/SwiftShader 实测） |
|---|---|---|---|
| 四类判别与真值一致率 | ≥95% | 98.4% | 98.3% |
| 发丝裂纹检出率 | ≥90% | 97.0%（误报 3.6%） | 94.4%（误报 1.5%） |
| 单盘 150 枚分析耗时 | <1.5s | ~0.22s | ~0.21s（软件渲染下；真实 GPU 更快） |

## 架构

```
src/
  sim/generator.ts      照蛋图合成器：按胚龄合成血管网/胚胎点/血环/晚死暗影/发丝裂纹，
                        纯像素运算（Node 可跑），输出灰度亮度 + 暖色 RGB + 真值
  analysis/features.ts  特征提取 CPU 参考实现：网格自动定位（行列质心精化）→ 每蛋 16 维特征
  analysis/classify.ts  规则判别器（阈值由 scripts/debug-*.ts 标定）
  analysis/runner.ts    蛋盘 → 图像 → 分析 → 落库；导入图仅存内存，合成盘按种子重生成
  gpu/pipeline.ts       WebGL2 管线：亮度 R32F 纹理 → 单通道 MRT(4×RGBA32F) 特征压缩，
                        与 CPU 版同一套数学（逐特征 diff≈0），失败自动回退 CPU
  store.ts              localStorage 持久化（批次/盘/结果/复核），复核修正回写统计
  ui/                   四个页面：入孵批次 / 照蛋结果 / 种鸡舍统计 / 人工复核
scripts/
  validate.ts           npm run validate 指标自检（Node，CPU 管线）
  debug-*.ts            阈值标定用的特征分布/误报分解/阈值扫描工具
```

### 判别原理（7 胚龄）

- **受精**：胚胎点响应（8px 环绕 − 3px 中心盒均值差）+ 内核区细暗线（血管网）
- **无精**：以上均无，蛋体透亮均匀
- **早死胚**：血环 —— 中环带(0.45~0.70R)暗像素占比显著高于内核
- **晚死胚**：整蛋透光差（绝对亮度均值低）+ 大片模糊暗影
- **发丝裂纹**：4 方向亮线滤波，响应 = 中心线 − max(两侧, 该半径壳面径向剖面)；
  要求中心"亮过壳面本身"，可排除血管间隙/血环边缘的伪亮线

每蛋基线（0.70~0.88R 环带均值）抵消整盘照度不均与蛋间亮度差异，无需全局归一化。

## 使用流程

1. **入孵批次**：新建批次（选种鸡舍、入孵日期、胚龄、盘数），自动建盘
2. **照蛋结果**：选盘 → 生成合成演示图（或导入实拍整盘照片）→ 运行分析 →
   整盘叠加图（绿=受精 黄=无精 橙=早死 红=晚死 紫圈=裂纹），点蛋看详情，导出 CSV
3. **人工复核**：低置信 + 裂纹 + 10% 抽检队列，快捷键 1-4 判定、C 切换裂纹；
   演示数据可"按合成真值一键复核"查看人机一致率
4. **种鸡舍统计**：按舍聚合受精率/死胚率/裂纹率，低于 90% 的舍标红并给出追溯提示

## 说明与边界

- 演示数据为合成图：三种舍基准受精率 84%（其余 91~95%），用于演示低受精率追溯
- 导入的实拍照片只存内存（结果持久化）；合成盘图片按种子确定性重生成，不占存储
- 判别器为可解释规则（非学习型）；接入真实照片后，可用复核页积累的人工标注
  重新标定 `src/analysis/classify.ts` 中的阈值（`TH`），或替换为模型推理
- 蛋盘规格默认 10×15=150，网格定位支持 ≤32×32
